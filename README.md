# 🎮 Minecraft-Inspired Voxel Game Engine

A modern Java-based voxel game engine built from scratch with LWJGL and OpenGL, inspired by classic sandbox games.

## ✨ Features

### 🏠 **Menu System**
- **Main Menu** - Beautiful UI with smooth animations and transitions
- **Singleplayer** - World creation, selection, and management
- **Multiplayer** - Server browser and LAN game support
- **Settings** - Comprehensive graphics, controls, and audio options
- **Pause Menu** - In-game accessibility and settings

### 🌍 **World Engine**
- **Infinite World Generation** - Procedurally generated voxel landscapes
- **Biome Diversity** - Forests, deserts, mountains, plains, oceans, and more
- **Cave Systems** - Complex underground networks and mineral distribution
- **Structures** - Generated villages, temples, and dungeons
- **Chunk System** - Efficient loading and unloading of world segments

### ⚡ **Physics & Graphics**
- **Voxel Rendering** - Optimized mesh generation and rendering
- **Dynamic Lighting** - Real-time block light and sky light
- **Day/Night Cycle** - Realistic time progression with celestial bodies
- **Fluid Simulation** - Water and lava physics with flow mechanics
- **Collision Detection** - Precise player and entity collision handling

### 👨‍💻 **Player System**
- **Dual Game Modes** - Survival (health, hunger, resources) and Creative (unlimited resources, flight)
- **Inventory Management** - 36-slot inventory with 9-slot hotbar
- **Block Interaction** - Breaking, placing, and using blocks
- **Crafting System** - 2x2 and 3x3 crafting interfaces
- **Combat Mechanics** - Mob AI, weapons, and damage system

## 🛠️ Technology Stack

- **Language**: Java 17+
- **Graphics**: LWJGL 3 + OpenGL 4.5
- **Mathematics**: JOML (Java OpenGL Math Library)
- **Audio**: OpenAL with spatial sound support
- **Windowing**: GLFW for cross-platform compatibility

## 📦 Installation

```bash
git clone https://github.com/RMMasterGG/TestGame.git
./gradlew build
./gradlew run
```

# 🎮 Воксельный Игровой Движок В Стиле Minecraft

Современный игровой движок для воксельных игр, написанный на Java с использованием LWJGL и OpenGL, вдохновленный классическими песочницами.

## ✨ Возможности

### 🏠 **Система Меню**
- **Главное Меню** - Красивый интерфейс с плавными анимациями
- **Одиночная Игра** - Создание, выбор и управление мирами
- **Сетевая Игра** - Подключение к серверам и LAN-игры
- **Настройки** - Графика, управление, звук
- **Меню Паузы** - Настройки во время игры

### 🌍 **Движок Мира**
- **Бесконечная Генерация** - Процедурно генерируемые воксельные ландшафты
- **Разнообразие Биомов** - Леса, пустыни, горы, равнины, океаны
- **Пещерные Системы** - Подземные сети и распределение ресурсов
- **Структуры** - Деревни, храмы, подземелья
- **Чанковая Система** - Эффективная загрузка сегментов мира

### ⚡ **Физика и Графика**
- **Воксельный Рендеринг** - Оптимизированное построение мешей
- **Динамическое Освещение** - Блочное и небесное освещение
- **Смена Дня и Ночи** - Реалистичная смена времени суток
- **Физика Жидкостей** - Вода и лава с механикой течения
- **Система Коллизий** - Точное определение столкновений

### 👨‍💻 **Система Игрока**
- **Два Режима** - Выживание (здоровье, голод) и Творчество (полет, ресурсы)
- **Управление Инвентарем** - 36 слотов + горячая панель
- **Взаимодействие с Блоками** - Разрушение и установка блоков
- **Система Крафта** - Верстак 2x2 и 3x3
- **Боевая Система** - ИИ мобов, оружие, урон

## 🛠️ Технологии

- **Язык**: Java 17+
- **Графика**: LWJGL 3 + OpenGL 4.5
- **Математика**: JOML
- **Звук**: OpenAL с 3D звуком
- **Окна**: GLFW

## 📦 Установка

```bash
git clone https://github.com/RMMasterGG/TestGame.git
./gradlew build
./gradlew run
```
